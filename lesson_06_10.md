## Вывод объектов и перегрузка операторов

В Python при работе со встроенными типами данных мы привыкли складывать числа через `+`, объединять строки или просто передавать переменную в `print()`. Но если мы попробуем вывести созданный нами объект класса или сложить два прямоугольника напрямую, интерпретатор выдаст ошибку или техническую строку вида `<__main__.Rectangle object at 0x...>`:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

r1 = Rectangle(3, 4)
print(r1)  # Выведет адрес в памяти, а не размеры!

```

Чтобы научить наши собственные классы стандартным операторам и командам Python, используются **специальные (магические) методы**. Их названия всегда начинаются и заканчиваются двойным подчёркиванием (dunder-методы: *double underscore*). С одним из них — `__init__` — вы уже знакомы.

---

### Метод `__str__`: строковое представление объекта

Когда функция `print()` получает объект, она внутри себя вызывает метод `__str__()` этого объекта. Если он не переопределён разработчиком, срабатывает стандартная реализация, возвращающая тип и адрес в памяти.

Метод `__str__` должен возвращать **строку (`str`)**, понятную человеку:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def __str__(self):
        return f"Прямоугольник {self.width}x{self.height}"

r1 = Rectangle(5, 10)
print(r1)  # Выведет: Прямоугольник 5x10

```

---

### Метод `__add__`: перегрузка оператора `+`

Когда мы пишем выражение `a + b`, Python под капотом вызывает метод: `a.__add__(b)`.

* `self` — левый операнд (`a`);
* `other` — правый операнд (`b`).

Результатом этого метода, как правило, становится **новый объект**:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def __add__(self, other):
        # Проверяем, что второй объект тоже прямоугольник
        if isinstance(other, Rectangle):
            # Создаём и возвращаем новый прямоугольник
            new_width = self.width + other.width
            new_height = self.height + other.height
            return Rectangle(new_width, new_height)
        return NotImplemented

```
