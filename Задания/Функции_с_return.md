### Задание 1. Калькулятор сдачи

Напишите функцию `calc_change(cost, paid)`, которая принимает:

* `cost` — стоимость покупки;
* `paid` — сумму, внесенную покупателем.

Функция должна вычислять и **возвращать** (`return`) размер сдачи.

**Основная программа:**

1. Вызовите функцию для покупки на `240` руб. при оплате купюрой в `500` руб.
2. Сохраните результат работы функции в переменную `change`.
3. Выведите результат на экран по образцу.

**Ожидаемый вывод:**

```text
Сдача: 260 руб.

```

### Задание 2. Ограничитель урона

В игре броня поглощает входящий урон. Напишите функцию `apply_armor(damage, armor)`, которая рассчитывает чистый урон по правилам:

* Если `damage > armor`, функция возвращает фактический урон: `damage - armor`.
* Если броня равна урону или превышает его (`damage <= armor`), урон полностью блокируется — функция должна вернуть `0`.

**Основная программа:**
Проверьте работу функции на двух разных ударах и напечатайте результат:

1. Сильный удар: урон `45`, броня `10`.
2. Слабый удар: урон `15`, броня `30`.

**Ожидаемый вывод:**

```text
Удар 1: 35 урона
Удар 2: 0 урона

```

### Задание 3. Карта постоянного покупателя

В магазине канцтоваров действует акция: если стоимость покупки превышает `500` рублей, покупатель получает скидку `100` рублей. Если заказ на `500` рублей или меньше, скидка не предоставляется.

Напишите функцию `apply_discount(total_cost)`, которая принимает общую стоимость заказа и рассчитывает сумму к оплате по правилам:

* Если `total_cost > 500`, функция возвращает сумму с учетом скидки: `total_cost - 100`.
* Если сумма равна `500` или меньше (`total_cost <= 500`), скидки нет — функция возвращает исходную стоимость `total_cost`.

**Основная программа:**
Проверьте работу функции на двух разных чеках и выведите результаты на экран:

1. Чек на сумму `650` руб.: `apply_discount(650)`.
2. Чек на сумму `320` руб.: `apply_discount(320)`.

**Ожидаемый вывод:**

```text
Чек 1 к оплате: 550 руб.
Чек 2 к оплате: 320 руб.

```

### Задание 4. Подсчет отличных оценок

Напишите функцию `count_fives(grades)`, которая принимает список школьных оценок и подсчитывает, сколько раз в нем встречается пятерка (`5`). Функция должна возвращать найденное количество через `return`.

**Основная программа:**
Дан список оценок за четверть:

```python
my_grades = [5, 4, 3, 5, 5, 4, 5, 2]

```

Передайте список `my_grades` в функцию, сохраните ответ в переменную и напечатайте итог.

**Ожидаемый вывод:**

```text
Количество пятерок: 4

```
