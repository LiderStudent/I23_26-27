## Математические операции в Python

| Знак | Название | Приоритет | Пример |
| :---: | :--- | :---: | :--- |
| `()` | Скобки (изменение порядка действий) | 1 (высший) | `(2 + 3) * 4` -> `20` |
| `**` | Возведение в степень | 2 | `2 ** 3` -> `8` |
| `*` | Умножение | 3 | `6 * 7` -> `42` |
| `/` | Деление (всегда результат - дробь) | 3 | `7 / 2` -> `3.5` |
| `//` | Целочисленное деление (нацело) | 3 | `7 // 2` -> `3` |
| `%` | Остаток от деления | 3 | `7 % 2` -> `1` |
| `+` | Сложение | 4 | `15 + 8` -> `23` |
| `-` | Вычитание | 4 (низший) | `20 - 7` -> `13` |

## Литерал vs Переменная

**Литерал** - это **само значение**, написанное прямо в коде. Оно неизменно.
*Примеры:* `5`, `42`, `"Привет"`, `3.14`.

**Переменная** - это **имя (коробочка с наклейкой)**, в которой лежит значение. Значение внутри можно читать, использовать в формулах или заменять на новое.
* *Примеры:* `x = 5`, `score = 100`, `name = "Анна"`.

**Главное правило:**
Везде, где можно написать литерал (число или строку), можно написать и переменную, в которой это значение лежит.

```python
# Работаем напрямую с литералами:
print(10 + 5)

# То же самое, но через переменные:
a = 10
b = 5
print(a + b)

```
