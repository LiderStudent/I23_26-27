### Создание окна

Программы с графическим интерфейсом работают в бесконечном цикле обработки событий (`mainloop`). Чтобы архитектура была удобной и расширяемой, всё состояние приложения и его внешний вид инкапсулируются внутри класса.

**Что делаем:**

1. Подключаем библиотеку `tkinter`.
2. Создаём класс `ClickerApp`. Конструктор `__init__` принимает `root` - главное окно.
3. Задаём заголовок, размер и цвет фона.

```python
import tkinter as tk


class ClickerApp:

  def __init__(self, root):
    # Сохраняем ссылку на окно
    self.root = root

    # Настройки окна
    self.root.title("Тап по хомяку")
    self.root.geometry("350x450")
    self.root.resizable(False, False)
    self.root.config(bg="#000000")  # Тёмный фон


# Точка входа в программу
if __name__ == "__main__":
  root = tk.Tk()  # Создание базового окна
  app = ClickerApp(root)  # Создание экземпляра нашего приложения
  root.mainloop()  # Запуск цикла обработки событий

```

> **Проверка:** Запустите скрипт. Должно появиться пустое тёмное окно фиксированного размера $350 \times 450$ с заголовком.

### Добавление надписи и кнопки

Любой элемент интерфейса в Tkinter называется **виджетом** (widget). Виджет сначала создаётся с указанием родительского контейнера и параметров, а затем размещается в окне (например, методом `.pack()`).

* `tk.Label` - статичный текст или надпись.
* `tk.Button` - кликабельная кнопка.

**Что делаем:**

1. В конструкторе `__init__` заводим атрибут `self.score = 0` для хранения количества очков.
2. Создаём надпись со счётом.
3. Создаём большую кнопку клика.

```python
import tkinter as tk


class ClickerApp:

  def __init__(self, root):
    self.root = root
    self.root.title("Мой первый кликер")
    self.root.geometry("350x450")
    self.root.resizable(False, False)
    self.root.config(bg="#000000")

    # Переменная состояния игры
    self.score = 0

    # Виджет текста
    self.label_score = tk.Label(
        self.root,
        text=f"СЧЁТ: {self.score}",
        font=("Arial", 26, "bold"),
        fg="#ffffff",  # Цвет текста
        bg="#202020",  # Цвет фона надписи
    )
    # Метод pack размещает элемент сверху вниз с отступом pady
    self.label_score.pack(pady=40)

    # Виджет кнопки
    self.btn_click = tk.Button(
        self.root,
        text="КЛИК!",
        font=("Arial", 18, "bold"),
        bg="#0000ff",  # Синий фон кнопки
        fg="#ffffff",  # Белый текст
        activebackground="#8080ff",  # Цвет при зажатии
        width=12,
        height=3,
        relief="raised",
        bd=4,
    )
    self.btn_click.pack(pady=20)


if __name__ == "__main__":
  root = tk.Tk()
  app = ClickerApp(root)
  root.mainloop()

```

> **Проверка:** На экране должна появиться надпись «Счёт: 0» и кнопка «КЛИК!». При нажатии на кнопку она визуально вдавливается, но счётчик пока не меняется.

### Назначение действия на нажатие кнопки

Чтобы кнопка реагировала на нажатие, ей передаётся аргумент `command`. В качестве значения указывается имя метода (без круглых скобок `()`), который должен сработать при клике.

Чтобы обновить текст надписи после изменения переменной, у виджета `Label` вызывается метод `.config(text=...)`.

**Что делаем:**

1. Описываем метод `on_click(self)`. В нём увеличиваем `self.score` на 1 и обновляем текст `self.label_score`.
2. В параметрах `self.btn_click` добавляем `command=self.on_click`.

```python
import tkinter as tk


class ClickerApp:

  def __init__(self, root):
    self.root = root
    self.root.title("Мой первый кликер")
    self.root.geometry("350x450")
    self.root.resizable(False, False)
    self.root.config(bg="#000000")

    self.score = 0

    self.label_score = tk.Label(
        self.root,
        text=f"СЧЁТ: {self.score}",
        font=("Arial", 26, "bold"),
        fg="#adbac7",
        bg="#22272e",
    )
    self.label_score.pack(pady=40)

    # Добавлен параметр command=self.on_click
    self.btn_click = tk.Button(
        self.root,
        text="КЛИК!",
        font=("Arial", 18, "bold"),
        bg="#0000ff",
        fg="#ffffff",
        activebackground="#8080ff",
        width=12,
        height=3,
        relief="raised",
        bd=4,
        command=self.on_click,
    )
    self.btn_click.pack(pady=20)

  def on_click(self):
    """Метод, вызываемый при каждом нажатии кнопки."""
    self.score += 1
    # Обновляем текст на экране
    self.label_score.config(text=f"СЧЁТ: {self.score}")


if __name__ == "__main__":
  root = tk.Tk()
  app = ClickerApp(root)
  root.mainloop()

```

> **Проверка:** Нажимайте на кнопку - число очков в окне должно увеличиваться на 1 с каждым кликом.

### Добавление картинки на кнопку кликера

В Tkinter для работы с изображениями используется класс `PhotoImage` (для PNG, GIF и базовых форматов).

При работе с изображениями в ООП важно помнить ключевое правило Tkinter: **картинку всегда нужно сохранять в атрибут объекта (`self.image = ...`)**, иначе сборщик мусора Python удалит её из оперативной памяти, и вместо рисунка отобразится пустое место.

**Что делаем:**

1. Положите файл картинки (например, `hamster.png`) в ту же папку, где лежит ваш `.py` скрипт. Желательно сразу подобрать картинку подходящего размера (примерно $150 \times 150$ или $200 \times 200$ пикселей).

2. Загружаем изображение с помощью `tk.PhotoImage(file="hamster.png")` и обязательно сохраняем его в `self.hamster_img`.
3. В параметрах кнопки `tk.Button` заменяем текст на изображение через параметр `image=self.hamster_img`.
4. Чтобы кнопка выглядела аккуратно (без серых рамок вокруг картинки), убираем границы с помощью `bd=0` и настраиваем фон кнопки в цвет окна.

```python
import tkinter as tk


class ClickerApp:

  def __init__(self, root):
    self.root = root

    ...

    # 1. Загрузка картинки (ВАЖНО сохранить через self.)
    self.hamster_img = tk.PhotoImage(file="hamster.png")

    # 2. Создание кнопки-картинки
    self.btn_click = tk.Button(
        self.root,
        image=self.hamster_img,  # Указываем изображение вместо text
        bg="#000000",  # Цвет фона кнопки под цвет окна
        activebackground="#000000",  # Фон при нажатии
        bd=0,  # Убираем границу кнопки
        relief="flat",  # Плоский стиль
        cursor="hand2",  # Курсор в виде пальца при наведении
        command=self.on_click,
    )

```

> **Проверка:** Отредактируйте и запустите скрипт. По центру окна должен отображаться хомяк.

**Если картинка слишком огромная:**  
  Встроенный `tk.PhotoImage` позволяет быстро уменьшить масштаб в целое число раз методом `.subsample(x, y)`:
  ```python
  # Уменьшить картинку в 2 раза по ширине и высоте

```
