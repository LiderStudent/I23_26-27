### Блок 1. Списки без циклов (индексы и базовые функции)

#### Задание 1. Рокировка в инвентаре

Дан список экипировки героя:

```python
items = ["Факел", "Щит", "Зелье", "Меч"]

```

1. Выведите на экран первый и последний предметы, используя положительный (`0`) и отрицательный (`-1`) индексы.
2. Поменяйте местами `"Факел"` и `"Меч"` (обращаясь к ним по индексам).
3. Выведите обновленный список на экран.

**Ожидаемый вывод:**

```text
Первый: Факел
Последний: Меч
Обновленный список: ['Меч', 'Щит', 'Зелье', 'Факел']
```

#### Задание 2. Удвоение очков

В мобильной игре активировался бонус «удвоение очков». Дан список набранных очков за каждый уровень:

```python
scores = [15, 40, 25, 80, 50]

```

С помощью цикла `for` пройдите по всем очкам в списке и выведите для каждого уровня сообщение с удвоенным значением очков по образцу.

**Ожидаемый вывод:**

```text
Удвоенные очки: 30
Удвоенные очки: 80
Удвоенные очки: 50
Удвоенные очки: 160
Удвоенные очки: 100

```

#### Задание 3. Детектор скидок

Дан список цен на товары:

```python
prices = [450, 1200, 300, 2500, 890, 1500]

```

С помощью цикла `for` пройдите по всем ценам и выведите только те, которые превышают `1000` рублей, сопроводив их текстом по образцу.

**Ожидаемый вывод:**

```text
Дорогой товар: 1200 руб.
Дорогой товар: 2500 руб.
Дорогой товар: 1500 руб.

```

runners = ["Алексей", "Мария", "Иван", "Дарья"]

#### Задание 6. Контроль заморозков

Дан список температур воздуха за неделю:

```python
weather = [3, -2, -5, 0, 1, -4, 2]

```

Создайте переменную-счетчик. С помощью цикла `for` и условия `if` посчитайте, сколько дней температура опускалась ниже нуля градусов (`< 0`). Итоговый результат выведите на экран после цикла.

**Ожидаемый вывод:**

```text
Дней с заморозками: 3

```
