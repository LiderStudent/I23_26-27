### Работа с JSON-файлами. Сохранение и загрузка прогресса

Когда программа закрывается, все данные из оперативной памяти (значение `self.score`, сила клика и купленные улучшения) стираются. Чтобы прогресс игрока сохранялся между запусками, его нужно записывать на диск.

Самый удобный формат для сохранения структур данных в Python - **JSON** (JavaScript Object Notation). Визуально и по структуре он почти полностью повторяет привычные словари (`dict`) и списки (`list`).

---

### Знакомство с модулем `json`

В Python библиотека для работы с JSON уже встроена, устанавливать её не нужно - достаточно написать `import json`.

Для работы с файлами используются две базовые функции:

* `json.dump(data, file)` - записывает словарь `data` в открытый файл `file`.
* `json.load(file)` - считывает данные из открытого файла `file` и возвращает готовый словарь Python.

**Как упаковать состояние игры в словарь:**

```python
data = {
    "score": self.score,
    "click_power": self.click_power,
    "upgrade_cost": self.upgrade_cost,
}

```

---

### Метод сохранения прогресса (`save_game`)

Чтобы записать данные, файл нужно открыть в режиме записи (`"w"` - write) с помощью менеджера контекста `with open(...)`.

**Что делаем:**

1. Подключаем модуль `import json` в самом верху файла.
2. Добавляем в класс `ClickerApp` метод `save_game(self)`:
* Собираем текущие атрибуты игры в словарь `data`.
* Открываем файл `"save.json"` на запись с кодировкой `utf-8`.
* Сохраняем словарь через `json.dump(data, file, indent=4)` (параметр `indent=4` делает файл красивым и читаемым для человека).



```python
import json


# ... внутри класса ClickerApp ...
def save_game(self):
  data = {
      "score": self.score,
      "click_power": self.click_power,
      "upgrade_cost": self.upgrade_cost,
  }
  with open("save.json", "w", encoding="utf-8") as file:
    json.dump(data, file, indent=4)
  print("Игра сохранена!")

```

### Метод загрузки прогресса (`load_game`)

При загрузке может возникнуть ситуация, что игрок нажал «Загрузить», но файла `"save.json"` ещё не существует (например, при самом первом запуске). Чтобы программа не упала с ошибкой `FileNotFoundError`, обернём чтение в блок `try / except`.

**Что делаем:**

1. Открываем `"save.json"` в режиме чтения (`"r"` - read).
2. Считываем словарь с помощью `json.load(file)`.
3. Достаём значения по ключам (метод `.get(ключ, значение_по_умолчанию)` защитит от ошибок, если в старом сохранении не было какого-то поля).
4. Обязательно обновляем текст на экране, чтобы пользователь сразу увидел загруженные цифры.

```python
def load_game(self):
  try:
    with open("save.json", "r", encoding="utf-8") as file:
      data = json.load(file)

    # Восстанавливаем атрибуты из словаря
    self.score = data.get("score", 0)
    self.click_power = data.get("click_power", 1)
    self.upgrade_cost = data.get("upgrade_cost", 10)

    # Обновляем интерфейс
    self.label_score.config(text=f"СЧЁТ: {self.score}")
    # Если есть кнопка улучшения, обновите её текст здесь же
    print("Прогресс загружен!")

  except FileNotFoundError:
    print("Файл сохранения не найден!")

```
