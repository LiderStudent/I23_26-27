### Задание 1. Конвертер минут

Напишите функцию `to_minutes(hours, minutes)`, которая принимает количество часов и минут и **возвращает** общее время в минутах (в одном часе `60` минут).

**Основная программа:**

1. Вызовите функцию для времени `2` часа `35` минут.
2. Сохраните ответ в переменную `total_min` и выведите его на экран.

**Ожидаемый вывод:**

```text
Всего минут: 155

```

### Задание 2. Проверка пароля по длине

Напишите функцию `check_password(password)`, которая принимает строку с паролем и проверяет его надежность:

* Если длина пароля (`len(password)`) равна `8` символам или больше, функция возвращает `"Надежный пароль"`.
* Если символов меньше `8`, функция возвращает `"Слишком короткий"`.

**Основная программа:**
Запросите пароль у пользователя через `input()`, передайте его в функцию и выведите результат проверки на экран.

**Пример работы:**

```text
Придумайте пароль: cat
Слишком короткий

```

```text
Придумайте пароль: supersecret
Надежный пароль

```

### Задание 3. Сумма чисел

Напишите функцию `sum_list(numbers)`, которая принимает список целых чисел, находит среди них только те, которые делятся на `3` без остатка (`x % 3 == 0`), складывает их и **возвращает** полученную сумму.

**Основная программа:**

```python
data = [3, 10, 9, 4, 15, 7, 6]

```

Передайте список `data` в функцию `sum_list` и напечатайте итоговую сумму.

**Ожидаемый вывод:**

```text
Сумма списка: 33

```

### Задание 4. Поиск лучшего результата

Напишите функцию `get_best_score(scores)`, которая принимает непустой список баллов за игру и **возвращает** самый большой балл из этого списка.

**Основная программа:**

```python
results = [42, 85, 19, 94, 67, 88]

```

Вызовите функцию для списка `results` и выведите рекордный счет.

**Ожидаемый вывод:**

```text
Лучший результат: 94

```
